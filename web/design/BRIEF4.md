# デザイン依頼書 その4：実機検証で見つかった2つのデザイン不具合

ヘッドレスブラウザで実際に描画して検証しました（29項目中28項目合格）。
残った問題のうち、**デザイン領域の2件**を修正してください。

対象ファイル: `web/styles.css` と `web/js/palette.js`
（`web/index.html`、`web/js/app.js`、`web/js/basemap.js` は Claude Code 担当。読むだけで編集禁止）

---

## 不具合A：`hidden` を付けたパネルが消えない（機能不全）

`web/index.html` では、詳細パネルを初期状態で隠すために標準の `hidden` 属性を使っています。

```html
<aside class="side-panel side-panel--detail" id="detail-panel" aria-hidden="true" hidden>
```

しかし `styles.css` の

```css
.side-panel--detail { display: flex; flex-direction: column; }
```

が `hidden` 属性の既定値（`display: none`）を**上書き**してしまい、
**ページを開いた瞬間に空の「トイレの情報」パネルが出たままになります**。

実測値: `hidden=true` なのに `getComputedStyle(...).display === "flex"`。

### 直してほしいこと

`hidden` 属性が付いている要素が確実に消えるようにしてください。
（`[hidden] { display: none !important; }` を置く、`.side-panel--detail:not([hidden])` に限定するなど、
方法は任せます。）
絞り込みパネル `#filter-panel` は現状正しく消えているので、そちらを壊さないでください。

## 不具合B：背景地図が薄すぎて、道路も建物も見えない（最重要）

`web/js/palette.js` の配色で実際に描画したところ、
**東京駅周辺のズーム16でも、道路・建物がほぼ見えません**。

添付のスクリーンショット（東京駅周辺・ズーム16・ライトモード・地図のみ）を見てください。
文字（注記）とトイレのマーカー以外、ほぼ真っ白です。

### 原因（実測）

地物はきちんと描画されています。データではなく**色の問題**です。
ズーム16の東京駅周辺で実際に描画された地物数:

| レイヤ | 地物数 | 現在の色 | 下地(land `#f5f6f2`)との明度差 |
|---|---|---|---|
| `building`（建物） | 590 | `#e7e2da` | ほとんど差がない |
| `building-outline` | 590 | `#d1c9bf` | わずか |
| `road-local`（市区町村道） | 216 | `#fcfcfa` | **下地より明るく、ほぼ見えない** |
| `roadLocalCase`（その縁） | 216 | `#e5e1da` | わずか |
| `road-pref`（都道府県道） | 106 | `#ffffff` | **ほぼ見えない** |
| `roadPrefCase` | 108 | `#d4c9bb` | わずか |
| `water`（水域） | 15 | `#d9edf4` | 薄い |

「マーカーを目立たせるため低彩度に」という前回の依頼を、
**明度差まで消してしまった**のが原因です。
彩度は低いままでよいので、**明度差（コントラスト）は付けてください**。

### 直してほしいこと

`web/js/palette.js` の light / dark 両方を、次を満たすように調整してください。

1. **ズーム15〜18の市街地で、道路網が地図として読み取れること。**
   GoogleマップやiPhoneのマップと同じく、
   「道路は下地よりはっきり明るい（または暗い）帯として見える」状態にしてください。
   そのために `land`（下地）を少し落ち着いた色にして、道路を白系で抜くのが定石です。
2. **建物が面として認識できること。** 下地との明度差を明確に付けてください。
3. 道路の階層（高速 > 国道 > 都道府県道 > 市区町村道）が、
   色と太さの両方で直感的に分かること。
4. **水域が一目で水と分かること。**
5. それでもなお、**トイレのマーカーが最も目立つ**こと。
   マーカーの色は次のとおりです（`styles.css` のトークン）。
   - 車いす対応あり: `--primary-strong` = `#005560`（濃い青緑）
   - 車いす対応なし: `--danger` = `#a52920`（濃い赤）
   - 不明: `--unknown` = `#596a77`（灰）
   背景地図にこれらと紛れる濃さ・色相を置かないでください。
6. 注記（地名）の可読性は現状よい（コントラスト比10:1前後）ので、維持してください。
7. `dark` も同様に、暗所で眩しくない範囲で道路・建物が判別できるようにしてください。

### 参考：色を確かめる方法

配色を変えたあと、次のコマンドで実際の描画を確認できます
（ローカルサーバは `http://127.0.0.1:8765/` で起動済みです）。

```
node scripts/probe_basemap.js
```

`data/shots/basemap-z14.png` `basemap-z16.png` `basemap-z18.png` が更新されます。
**必ず自分で実行して、画像を見て、道路と建物が見えることを確認してから提出してください。**
