# デザイン依頼書：日本全国トイレマップ

あなた（Codex）は本プロジェクトの **デザイン担当** です。
統括はClaude Codeが行い、地図ロジック・データ処理はClaude Code側が実装します。
**あなたはデザイン成果物（CSS / HTMLマークアップ / SVGアイコン / デザイン仕様）だけを作成してください。**
JavaScriptの地図ロジック（MapLibre初期化、データ読み込み、フィルタ処理）は書かないでください。

## 1. プロダクト概要

日本全国の「誰でも使えるトイレ」（公衆トイレ・公共施設のトイレなど）を地図上に表示するWebアプリ。
- データ: OpenStreetMap（Overpass API で取得済み、約N万件）
- 地図エンジン: MapLibre GL JS v5（ベクタータイル）
- 背景地図: 国土地理院ベクトルタイル（optimal_bvmap-v1）
- ホスティング: GitHub Pages（静的サイト、ビルドツールなし。素のHTML/CSS/JS）

## 2. 絶対要件（ユーザー本人の指定）

1. **老若男女問わず誰でも見やすく、使いやすいデザイン**（最重要。高齢者・子ども・視力の弱い人も含む）
2. GoogleマップやiPhoneの「マップ」アプリのような、馴染みのある操作感・見た目
3. 拡大・縮小・スクロールができる
4. 拡大しても画質が荒くならない（＝アイコンは必ずSVG。ラスター画像・絵文字フォント依存は禁止）
5. 嘘・いい加減な表現をしない（データが無い項目は「不明」と正直に表示する。推測で断定しない）

## 3. 表示すべきトイレの属性（データモデル）

各トイレは以下のフィールドを持つ。値が無い場合は `null`（＝不明）。

| キー | 意味 | 取りうる値 |
|---|---|---|
| `name` | 名称 | 文字列 / null |
| `multi` | 多目的トイレ（車いす対応・だれでもトイレ） | `"yes"`（あり） / `"limited"`（一部対応） / `"no"`（なし） / null（不明） |
| `style` | 便器の種類 | `"seated"`（洋式） / `"squat"`（和式） / `"both"`（洋式・和式の両方） / null（不明） |
| `male` | 男子トイレ | true / false / null |
| `female` | 女子トイレ | true / false / null |
| `unisex` | 共用（男女共用） | true / false / null |
| `baby` | おむつ交換台 | true / false / null |
| `ostomate` | オストメイト対応 | true / false / null |
| `fee` | 有料か | true（有料） / false（無料） / null |
| `hours` | 利用時間 | 文字列（例 `"24/7"`, `"09:00-17:00"`） / null |
| `access` | 利用条件 | `"public"`（誰でも） / `"customers"`（施設利用者・客のみ） / `"permissive"` / null |
| `operator` | 管理者 | 文字列 / null |
| `osmid` | OSM要素ID | 例 `"node/123456"` |

## 4. 必要なUI要素（すべてデザインしてください）

### 4-1. ヘッダー / 検索
- アプリ名（「トイレマップ」など短く）
- 地名・住所の検索ボックス（国土地理院の住所検索APIを使用予定）
- 検索候補のドロップダウンリスト

### 4-2. 地図上のコントロール
- 拡大 (+) / 縮小 (−) ボタン
- 現在地ボタン
- 方位リセット（北を上に戻す）ボタン
- 縮尺バー（MapLibreの標準ScaleControl用のスタイル上書き）

### 4-3. マーカー（最重要）
地図上の各トイレを表すマーカーを **SVG** でデザインしてください。
- **色だけに頼らない**（色覚特性のある人のため、形・記号でも区別できること）
- 以下の3種類を視覚的に区別:
  - A: 多目的トイレ **あり**（`multi = "yes"`）
  - B: 多目的トイレ **なし**（`multi = "no"` または `"limited"`）
  - C: 多目的トイレ **不明**（`multi = null`）
- 小さい表示（地図上32px程度）でも判別できること
- 選択中のマーカーを強調する状態も定義すること
- 密集時のクラスター（「128」など件数を表示する丸）のデザインも必要

### 4-4. 絞り込み（フィルタ）パネル
チェックボックス / トグルで以下を絞り込む:
- 多目的トイレあり
- 洋式あり
- 和式あり
- 男女別あり
- 共用あり
- おむつ交換台あり
- オストメイト対応
- 24時間利用可
- 無料
- 誰でも利用可（客のみを除く）

スマホでは下から出るシート、PCではサイドパネルが望ましい。

### 4-5. 詳細カード（トイレを選んだとき）
名称・属性一覧・利用時間・管理者・OSMへのリンク・「経路案内」ボタン（Googleマップを開く）。
属性は **アイコン＋文字ラベル** の両方で示すこと。不明な項目は「不明」とグレー表示。
スマホでは画面下部のボトムシート（ドラッグで高さ変更できる見た目）、PCでは左パネル。

### 4-6. 凡例（レジェンド）
マーカーの意味を説明する常設または開閉式の凡例。

### 4-7. その他
- 読み込み中の表示
- 「この範囲にトイレが見つかりません」の空状態
- 文字サイズ切替（標準 / 大）のトグル ※高齢者向け
- 出典表記（OpenStreetMap contributors / 国土地理院）

## 5. デザイン制約

- **フレームワーク禁止**（Tailwind, Bootstrap等は使わない）。素のCSSのみ。
- 外部CSSの読み込み禁止。フォントはシステムフォントスタック（日本語対応）を使うこと。
- CSS変数（カスタムプロパティ）でデザイントークンを定義すること。
- ライトモードを主とし、`prefers-color-scheme: dark` でダークモードにも対応。
- タップ領域は最小 **48×48px**。本文の基本文字サイズは **16px以上**、フィルタ等のラベルは17px以上。
- コントラスト比は WCAG 2.1 AA（本文4.5:1以上、大きい文字3:1以上）を満たすこと。
- 画面幅 320px（小型スマホ）〜 1920px（PC）まで破綻しないこと。
- `prefers-reduced-motion` に対応。
- キーボード操作でのフォーカスリングを明確に。

## 6. 提出物（このファイルと同じ web/design/ 配下に作成）

1. `web/design/DESIGN_SPEC.md`
   - デザインの方針、カラーパレット（HEXとコントラスト比の実測値）、タイポグラフィスケール、
     余白スケール、マーカーの意味論、アクセシビリティ対応内容 を記述。
2. `web/styles.css`
   - 全UIのスタイル。CSS変数によるトークン定義から始めること。
   - 使用するクラス名を DESIGN_SPEC.md に一覧化すること。
3. `web/design/ui.html`
   - 上記4章のUI要素すべての **HTMLマークアップ断片**（`<body>`の中身のみ）。
   - Claude Code がこれを index.html に組み込み、JSを結線します。
   - JSから操作しやすいよう、要素には `id` を付けること（例 `id="filter-panel"`）。
   - ARIA属性（role, aria-label, aria-expanded 等）を適切に付与すること。
4. `web/design/icons.js`
   - `window.TMIcons` というオブジェクトを定義するだけの純粋なデータ/文字列ファイル。
   - 中身: 各種SVGアイコンの文字列（多目的/洋式/和式/男性/女性/共用/おむつ/オストメイト/
     有料/無料/時計/現在地/検索/＋/−/方位/閉じる/経路案内 など）。
   - さらに `window.TMIcons.marker(kind, selected)` のような、
     マーカーSVG文字列を返す小さな純関数を含めてよい（kind: 'yes'|'no'|'unknown'）。
   - **すべてSVG。絵文字は使わない。** `currentColor` を活用すること。

## 7. 進め方

- 上記4章のUI要素に **抜け漏れがないこと** を自分で確認してから提出してください。
- `web/design/ui.html` のクラス名と `web/styles.css` のセレクタが **完全に一致** していることを確認してください。
- 文言はすべて **日本語**。専門用語は避け、高齢者にも通じる平易な言葉を使ってください。
  （例: 「多目的トイレ」には「車いす対応」の補足を添える）
- 作業が終わったら、作成した4ファイルのパスと、各ファイルの行数を報告してください。
