# デザイン依頼書 その5：「データについて」パネルと、絞り込みの注意書き

## 背景（なぜ必要か）

このアプリのトイレ情報は OpenStreetMap が出典です。実データを集計したところ、
**項目によって「記録がある割合」が大きく違う**ことが分かりました。

| 項目 | 記録がある件数 | 割合 |
|---|---:|---:|
| 全掲載件数 | 31,704 件 | — |
| 多目的トイレ（車いす対応） | 6,635 件 | 20.9% |
| 便器の種類（洋式・和式） | 866 件 | **2.7%** |
| 男子トイレの有無 | 2,311 件 | 7.3% |
| 女子トイレの有無 | 2,334 件 | 7.4% |
| 共用の有無 | 2,202 件 | 6.9% |
| おむつ交換台 | 1,730 件 | 5.5% |
| オストメイト対応 | 79 件 | 0.2% |
| 料金 | 5,310 件 | 16.7% |
| 利用条件 | 5,246 件 | 16.5% |
| 利用時間 | 702 件 | 2.2% |

利用者が「洋式あり」で絞り込むと数百件しか出ませんが、これは
**「洋式トイレが数百件しかない」のではなく「洋式だと記録されている場所が数百件しかない」**
という意味です。ここを誤解させないことが、このアプリでいちばん大事な設計課題です。

このアプリは「嘘をつかない・いい加減なことをしない」を最優先にしています。
利用者が誤解しないためのデザインを作ってください。

## 作ってほしいもの

対象ファイル: `web/styles.css` と `web/design/ui-info.html`（新規）
（`web/index.html` と `web/js/*.js` は Claude Code 担当。読むだけで編集禁止）

### 1. 「データについて」を開くボタン

地図右側のコントロール群（`#map-controls` の中、`.map-control` と同じ見た目）に、
もう1つボタンを足す前提で **HTMLの断片とCSS** を用意してください。

- `id="open-info"`、`aria-label="データについて"`、`aria-controls="info-panel"`
- アイコンは既存の `web/design/icons.js` に無いので、
  **`icons.js` に `info` という名前のSVGアイコンを追加**してください
  （既存の `frame(...)` の書き方に合わせること）。

### 2. 「データについて」パネル

既存の `.side-panel`（絞り込み・詳細と同じ体裁。スマホでは下からのシート、
PCでは左のパネル）として設計してください。

- 外側: `<aside class="side-panel side-panel--info" id="info-panel" ... hidden>`
- ヘッダー: タイトル「データについて」＋閉じるボタン `id="close-info"`
- 中身として、次の要素を **id 付きで** 用意してください。
  Claude Code が `web/data/meta.json` の実データを流し込みます。

| id | 入る内容 |
|---|---|
| `info-total` | 総件数（例「31,704 件」） |
| `info-updated` | データの取得日（例「2026年8月23日」） |
| `info-coverage` | 項目ごとの「記録がある割合」の一覧（下記） |
| `info-note` | 誤解を避けるための説明文（下記の文面を使ってください） |

`#info-coverage` の中は、**項目ごとに1行**を JavaScript が生成します。
そのため、次のような **1行分のひな形** をCSSクラス付きで設計してください。

- 行: `.coverage-row`
- 項目名: `.coverage-row__label`（例「便器の種類（洋式・和式）」）
- 割合を視覚的に示すバー: `.coverage-row__bar` と、その中身 `.coverage-row__fill`
  （`style="width: 2.7%"` を JavaScript が付けます）
- 数値: `.coverage-row__value`（例「2.7%（866件）」）

割合が低いことが **ひと目で伝わる** 見せ方にしてください。
バーの色は、割合が低いときに「注意」だと分かる配色（`--warning` 系）を使うなど、
**色だけに頼らず、数値も必ず併記**してください。

`#info-note` に入れる文面（そのまま使ってください）:

> この地図の情報は、世界中の有志が作る自由な地図「OpenStreetMap」を出典としています。
> 記録が無い項目は、推測で埋めずに「不明」と表示しています。
>
> 「不明」が多いのは、その設備が無いという意味ではなく、
> まだ誰も記録していないという意味です。
> 絞り込みで出てくる件数も、「記録がある場所」の件数です。

さらに、出典表記へのリンクを入れてください。

- OpenStreetMap contributors → `https://www.openstreetmap.org/copyright`
- 国土地理院 → `https://maps.gsi.go.jp/development/ichiran.html`

### 3. 絞り込みパネルへの注意書き

既存の `#filter-panel` の中、`.filter-list` のすぐ上に入れる
**注意書きのブロック**を設計してください。

- `id="filter-caveat"`、クラスは `.filter-caveat`
- 文面（そのまま使ってください）:

> 絞り込みは「記録がある場所」だけが対象です。
> 記録が無い場所（不明）は絞り込みの結果に出ません。

- 目立ちすぎず、しかし必ず読まれる程度の存在感にしてください。

### 4. 詳細パネルの「不明」の見せ方

現在 `.attribute-row__value--unknown` は灰色文字だけです。
「情報が無いだけで、設備が無いわけではない」と伝わるように、
**詳細パネルの属性一覧の下に一文** を置けるようにしてください。

- `id="detail-unknown-note"`、クラス `.detail-note`
- 文面: 「『不明』は、まだ記録が無いという意味です。設備が無いとは限りません。」
- JavaScript が、不明の項目が1つ以上あるときだけ表示します（`hidden` を付け外しします）。
