# トイレマップ — 日本全国の誰でも使えるトイレ

**▶ 公開先: https://yangxiangzuomu738-stack.github.io/japan-toilet-map/**

日本全国の公衆トイレ・公共施設のトイレを地図で探せる Web アプリです。
多目的トイレ（車いす対応）、洋式・和式、男子／女子トイレ・共用の有無を、
分かる範囲で正直に表示します。

- 掲載件数: **33,541 件**（日本全国）
  - トイレそのものが地図に記録されているもの: 31,704 件
  - 施設に「トイレあり」とだけ記録されているもの: 1,837 件
- 地図: 国土地理院ベクトルタイル（ベクター描画なので、拡大しても文字や線がぼやけません）
- 拡大・縮小・スクロール、現在地表示、10種の絞り込み、地名検索に対応
- **駅・駅ビル・スーパーなど商業施設の中のトイレも表示**。施設名で検索・絞り込みができる
- 地図のマーカーだけでなく **一覧** からも選べる（キーボード操作・スクリーンリーダー対応）
- 文字サイズ切替、ダークモード対応、色だけに頼らない印（色覚特性に配慮）
- ビルドツール不要の静的サイト（HTML / CSS / JavaScript のみ）

## データについて（重要・正直な説明）

このアプリのトイレ情報は **OpenStreetMap**（世界中の有志が作る自由な地図）を出典としています。
日本全国を網羅する、機械可読で自由に使えるトイレのデータは、実質これしかありません。

そのため、**項目によっては「不明」が非常に多い**という限界があります。
アプリ上では、記録が無い項目を推測で埋めず、そのまま「不明」と表示します。

| 項目 | 記録がある件数 | 割合 |
|---|---:|---:|
| どこにあるか（駅・施設・公園など） | 23,558 件 | 70.2% |
| 多目的トイレ（車いす対応） | 7,052 件 | 21.0% |
| 便器の種類（洋式・和式） | 920 件 | **2.7%** |
| 男子トイレの有無 | 2,311 件 | 6.9% |
| 女子トイレの有無 | 2,334 件 | 7.0% |
| 共用の有無 | 2,202 件 | 6.6% |
| おむつ交換台 | 1,843 件 | 5.5% |
| オストメイト対応 | 79 件 | 0.2% |
| 料金（有料・無料） | 5,310 件 | 15.8% |
| 利用条件 | 5,610 件 | 16.7% |
| 利用時間 | 1,878 件 | 5.6% |

場所の内訳（2026年8月24日時点）:

| 場所の種類 | 件数 |
|---|---:|
| 駅・駅ビル | 2,902 件 |
| 商業施設（スーパー・百貨店・モールなど） | 1,598 件 |
| 公園 | 15,381 件 |
| 道の駅・SA/PA | 1,510 件 |
| 公共施設（市役所・図書館・公民館など） | 1,137 件 |

うち 16,683 件は施設の**中**、6,875 件は施設の**そば**です。

（`npm run build:data` を実行すると最新化されます）

**とくに「洋式・和式」は 2.7% しか記録がありません。**
絞り込みで「洋式あり」を選ぶと数百件しか出ませんが、
これは「洋式トイレが数百件しかない」という意味ではなく、
**「洋式だと記録されているものが数百件しかない」** という意味です。
アプリ内の絞り込みパネルにも同じ注意書きを表示しています。

情報を増やすには、OpenStreetMap に直接タグを追加するのが確実です。
詳細パネルの「OpenStreetMap で元データを見る」から、その場所の元データへ移動できます。

### 「どこにあるトイレか」の判定方法

駅や商業施設の中のトイレは、OpenStreetMap では**名前が付いていないことがほとんど**です。
そのままでは「新宿駅」と検索しても駅の中のトイレは見つかりません。

そこで、各トイレに **どの施設の中／そばにあるか** を機械的に結び付けています。

1. 各都道府県で、トイレの周辺にある施設（駅・商業施設・公園・道の駅・公共施設）を
   OpenStreetMap から集めます（`scripts/fetch_places.py`）。
2. 施設の外接矩形に入るトイレを候補として絞り込みます。
3. 候補になった施設だけ、**実際の敷地・建物の形状**を取り直します。
4. 形状の中に入っていれば「〇〇の中」、入っていなければ距離で「〇〇のそば（約35m）」
   とします（`scripts/assign_places.py`）。

除外している紛らわしいもの:

- **建物の中のテナント**（`indoor` / `room` / `level` が付いた店など）。
  これを入れると、駅のトイレが「駅ナカの惣菜店のそば」になってしまいます。
- **路線の関係（〇〇新幹線など）**。外接矩形が数百kmに及び、
  沿線のトイレを片端から巻き込んでしまいます。
- 外接矩形が大きすぎる図形（駅・商業施設なら1〜1.5km、公園なら15kmを上限）。

検証: `scripts/audit_places.py` が、「〇〇の中」と表示している場所を無作為に選び、
**Overpass の `is_in`（その座標を含む面を返す機能）** で独立に確かめます。
2026年8月24日の実行では **25件中25件が一致**しました。

**「中」と言えるのは、実際の形状の中に入っているときだけ**です。
外接矩形は実際の敷地より広いので、それだけでは「中」とは言いません。
形状が取れなかった施設は「そば」に格下げしています。

### 施設に「トイレあり」とだけ記録されている場所

OpenStreetMap には、トイレそのものではなく **施設側に `toilets=yes`** と
記録されている場所があります（全国 2,562 件）。
これらも掲載していますが、**建物のどこにトイレがあるかは記録されていません**。

- 地図の印は施設の代表点です（トイレの正確な位置ではありません）
- そのため、**破線の枠の付いた別のマーカー**で表示し、
  詳細にも「地図の印は施設の代表点です」と明記しています
- 近く（120m以内）に本物のトイレの記録がある場合は、
  そちらの方が正確なので重複掲載しません

### 掲載対象

`amenity=toilets` のうち、`access=private` / `access=no`（＝関係者以外使えない）を
除いたものを掲載しています（151 件を除外）。
`access=customers`（施設利用者・お客様のみ）は、
利用条件を明記したうえで掲載し、絞り込みで除外できるようにしています。

## 使い方

1. 地図をドラッグして動かし、ピンチまたは ＋ / − ボタンで拡大・縮小します。
2. マーカーを選ぶと、そのトイレの詳細が開きます。
3. 一覧ボタンを押すと、**いま地図に写っている範囲のトイレを近い順に並べた一覧**が開きます。
   小さなマーカーを押すのが難しいときや、キーボードだけで操作したいときはこちらが便利です。
4. 「絞り込み」から、車いす対応・洋式・和式・おむつ交換台などで絞り込めます。
5. 検索欄に地名や住所を入れると、その場所へ移動します。
6. 右上の「文字」で、文字の大きさを「標準」「大」に切り替えられます。
7. 「データについて」で、項目ごとに何%記録があるかを確認できます。

### マーカーの意味

| 印 | 意味 |
|---|---|
| 濃い青緑のピン（人のマーク） | 車いす対応（多目的トイレ）あり |
| 赤い盾（×） | 車いす対応なし・一部対応 |
| 灰色のひし形（?） | 車いす対応は不明 |
| 数字入りの丸 | その付近に複数のトイレがあります（拡大すると分かれます） |

色だけでなく形でも区別しているので、色の見え方に特性がある方でも判別できます。

## ローカルで動かす

```bash
python -m http.server 8765 --directory web
```

ブラウザで `http://127.0.0.1:8765/` を開きます。
（`web/` 以下は静的ファイルのみなので、どんな静的サーバーでも動きます）

## データを最新にする

```bash
python scripts/fetch_osm.py          # 都道府県ごとに Overpass API から取得
python scripts/fetch_places.py       # 施設（駅・商業施設・公園など）を取得
python scripts/assign_places.py      # 各トイレに「場所」を結び付ける
python scripts/build_data.py         # web/data/*.json を生成
```

全国一括の取得は `scripts/verify_all.ql` を Overpass API に投げて
`data/national.json` として保存します（`build_data.py` はこれを正とします）。

## 動作を検証する

```bash
npm install
node scripts/verify.js               # ヘッドレスブラウザで機能を自動検証
node scripts/probe_basemap.js        # 背景地図の描画を層ごとに数える
node scripts/shot.js gpu 139.7671 35.6812 16 light 1200 800 map
python scripts/audit_data.py 40      # 表示内容を OSM の原本と突き合わせる
python scripts/audit_places.py 25    # 「〇〇の中」の判定を OSM の is_in で確かめる
```

`data/shots/` にスクリーンショットが出力されます。

> **見た目の確認は必ず `scripts/shot.js` を使ってください。**
> ヘッドレスのソフトウェア描画（SwiftShader）では
> `fill` と `line` のシェーダがコンパイルできず、
> 道路・建物・水域が描画されないことがあります（文字とアイコンだけが出ます）。
> `scripts/shot.js` は実GPUのChromeを使うため、本物の見た目が確認できます。

`scripts/audit_data.py` は、アプリのデータからランダムに選んだ件について
OpenStreetMap API で元のタグを取り直し、
アプリが表示する値（多目的トイレ・便器の種類・男女別・共用・料金・利用条件など）が
原本と一致するか検査します。
2026年8月23日の実行では **40件中40件が一致**しました。

## 構成

```
web/
  index.html          画面の骨組み
  styles.css          デザイン一式        ← Codex（デザイン担当）
  design/
    BRIEF1〜5.md         デザイン依頼書       ← Claude Code から Codex への指示
    DESIGN_SPEC.md    デザイン仕様書       ← Codex
    icons.js          SVGアイコン集        ← Codex
    ui.html           UIマークアップ原案    ← Codex
  js/
    palette.js        背景地図の配色        ← Codex
    basemap.js        地図スタイルの組み立て ← Claude Code
    data.js           データの復号と絞り込み ← Claude Code
    app.js            画面の結線と地図操作   ← Claude Code
  data/
    points.json       座標と属性（ビット詰め）
    details.json      名称・時間・管理者・OSM ID
    meta.json         件数と網羅率
  vendor/
    maplibre-gl.js    MapLibre GL JS v5.6.0 (BSD-3-Clause)
scripts/
  fetch_osm.py        Overpass API から取得
  build_data.py       アプリ用データを生成
  verify.js           自動検証
  probe_*.js          描画の診断
```

### 自動更新

`.github/workflows/refresh-data.yml` が毎月1日に OpenStreetMap からデータを取り直し、
変更があれば自動でコミットします（手動実行も可能）。
